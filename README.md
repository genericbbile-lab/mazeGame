Maze Game

This is a game where you navigate a randomized maze and collect coins. There are two monsters that will try to get you.

Radar-3 coins: allows you to see where the monsters are for a turn(Button: r)

Trap-3 coins: Place down to stun a monster for 3 turns(Button: t)

Travel-4 coins: Travel back 5 turns(Button: g)

Blockade-1 coin: Build an unbreakable wall(Button: b)

Easy Mode:
- Start with 20 coins
- Monsters are visible

Hard Mode
- Start with 0 coins
- Monsters are invisible

WASD - navigation
